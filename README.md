# 📐 Matematika Sang Juara: Tantangan Olimpiade SD

Game edukasi interaktif matematika berbasis web untuk siswa Sekolah Dasar (SD) yang dirancang untuk mengasah kemampuan pemecahan masalah, nalar kritis, dan persiapan kompetisi/olimpiade sains matematika.

---

## ✨ Fitur Utama

- **🏆 Mode Olimpiade Sains & Nalar SD**: Kumpulan paket soal matematika menantang mulai dari aritmatika cepat, pecahan, KPK/FPB, geometri, hingga teka-teki logika nalar.
- **🃏 Mode Permainan 24 (Make 24)**: Game asah otak menggunakan 4 angka acak dan operator dasar (+, -, ×, ÷) untuk mencapai hasil 24.
- **📝 Papan Cakar Interaktif (Scratchpad)**: Kanvas coret-coret digital langsung di layar untuk berhitung dan menggambar coretan matematis.
- **🔊 Efek Suara Web Audio API**: Efek suara sintetis dinamis tanpa memerlukan aset file audio eksternal.
- **🎉 Animasi & Perayaan Kemenangan**: Perayaan confetti visual saat menyelesaikan tantangan dengan gemilang.
- **📱 Desain Modern & Responsif**: Tampilan antarmuka futuristik, bersih, dan nyaman digunakan di berbagai ukuran layar.

---

## 🚀 Cara Menjalankan

Aplikasi ini dibuat murni menggunakan teknologi web modern (**Vanilla HTML5, CSS3, & JavaScript**), sehingga dapat dijalankan langsung di peramban (browser) tanpa instalasi dependensi tambahan:

1. Unduh atau clone repositori ini:
   ```bash
   git clone https://github.com/mercydella/proyek-matematika.git
   ```
2. Buka folder proyek:
   ```bash
   cd proyek-matematika
   ```
3. Buka file `index.html` langsung di peramban favorit Anda (Google Chrome, Microsoft Edge, Firefox, dll.).

---

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Semantik struktur web.
- **CSS3**: Desain modern responsif, gradasi warna, dan animasi UI.
- **JavaScript (ES6+)**: Logika permainan, generator soal, kalkulator 24 solver, dan manajemen skor.
- **Canvas API**: Untuk coret-coretan papan cakar dan efek confetti.
- **Web Audio API**: Efek suara dinamis langsung dari browser.
